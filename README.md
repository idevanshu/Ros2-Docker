</p>

<h2 style="color:#58a6ff;border-left:4px solid #1f6feb;padding-left:12px;margin-top:40px;">What This Project Does</h2>

<p>This project solves the pain of manually setting up ROS 2 on Windows. You run <b>one PowerShell script</b> and it handles everything:</p>
<p><b>1.</b> Scans your Windows hardware for all installed GPUs using Win32_VideoController</p>
<p><b>2.</b> Generates a GPU-specific Dockerfile &mdash; NVIDIA gets CUDA passthrough, AMD/Intel gets Mesa D3D12</p>
<p><b>3.</b> Generates a matching docker-compose.yml with correct device mounts and environment variables</p>
<p><b>4.</b> Creates the local workspace/ folder and the full YOLOv8 ROS 2 package structure inside it</p>
<p><b>5.</b> Builds the Docker image and starts the container automatically</p>
<p>After setup, a ROS 2 Python node subscribes to <b>/camera/image_raw</b>, runs YOLOv8n ONNX inference on every frame, draws bounding boxes, and publishes annotated output to <b>/yolo/detection_image</b>.</p>

<h2 style="color:#58a6ff;border-left:4px solid #1f6feb;padding-left:12px;margin-top:40px;">Prerequisites</h2>

<p><b>Docker Desktop</b> &mdash; Install from docker.com. Enable WSL 2 backend in Settings. Must be running before executing the script.</p>
<p><b>PowerShell 7 (recommended)</b> &mdash; Install via <code style="color:#79c0ff;background:#161b22;padding:2px 6px;border-radius:4px;">winget install Microsoft.PowerShell</code>. PowerShell 5.1 works but may have encoding issues with emojis.</p>
<p><b>NVIDIA Container Toolkit</b> (NVIDIA GPUs only) &mdash; Must be installed inside your WSL 2 distro. Without it the container cannot access the GPU. Install guide: docs.nvidia.com/datacenter/cloud-native/container-toolkit</p>
<p><b>CUDA 12 + cuDNN 9</b> (for GPU inference) &mdash; Required only if you want YOLOv8n to run on your NVIDIA GPU via onnxruntime-gpu. Without these the node falls back to CPU automatically.</p>


<h2 style="color:#58a6ff;border-left:4px solid #1f6feb;padding-left:12px;margin-top:40px;">Quick Start</h2>

<h2 style="color:#58a6ff;border-left:4px solid #1f6feb;padding-left:12px;margin-top:40px;">Multi-GPU Detection Logic</h2>

<h2 style="color:#58a6ff;border-left:4px solid #1f6feb;padding-left:12px;margin-top:40px;">YOLOv8n Node Details</h2>

<p>The node is a standard ROS 2 Python node built with <b>rclpy</b>. It uses <b>onnxruntime</b> for inference and <b>cv_bridge</b> to convert between ROS Image messages and OpenCV frames.</p>
<p><b>Input topic:</b> <code style="color:#79c0ff;background:#161b22;padding:2px 6px;border-radius:4px;">/camera/image_raw</code> &mdash; sensor_msgs/Image in bgr8 encoding</p>
<p><b>Output topic:</b> <code style="color:#79c0ff;background:#161b22;padding:2px 6px;border-radius:4px;">/yolo/detection_image</code> &mdash; annotated sensor_msgs/Image with bounding boxes drawn</p>
<p><b>Model input:</b> Resized to 640x640, normalized to [0,1], BGR to RGB converted</p>
<p><b>Model output:</b> Shape (1, 84, 8400) &mdash; 84 = 4 box coords + 80 COCO class scores, 8400 anchor proposals</p>
<p><b>Confidence threshold:</b> 0.5 &mdash; only detections above this are drawn</p>

<pre style="background:#161b22;border:1px solid #30363d;border-radius:8px;padding:18px;overflow-x:auto;font-size:13px;">
<code style="color:#79c0ff;font-family:Courier New,monospace;">/camera/image_raw  -->  [YoloNode]  -->  preprocess (640x640)
                              |
                        onnxruntime session
                              |
                        parse (1, 84, 8400)
                              |
                        filter conf &gt; 0.5
                              |
                   draw boxes + class labels
                              |
                  /yolo/detection_image (bgr8)</code>
</pre>


<h2 style="color:#58a6ff;border-left:4px solid #1f6feb;padding-left:12px;margin-top:40px;">Testing Without a Camera</h2>

<p>Run this inside the container to test inference on a static image and save the annotated result to your Windows workspace folder:</p>

<pre style="background:#161b22;border:1px solid #30363d;border-radius:8px;padding:18px;overflow-x:auto;"><code style="color:#79c0ff;font-family:Courier New,monospace;">python3 &lt;&lt; 'EOF'
import onnxruntime as ort
import numpy as np
import cv2

img = cv2.imread('/ros2_ws/your_test_image.jpg')
inp = cv2.resize(img, (640, 640))
inp = inp[:,:,::-1].transpose(2,0,1).astype(np.float32) / 255.0
inp = np.ascontiguousarray(inp)[np.newaxis]

sess = ort.InferenceSession('/ros2_ws/yolov8n.onnx',
    providers=['CPUExecutionProvider'])
out = sess.run(None, {sess.get_inputs()[0].name: inp})

count = 0
for det in out[0][0].T:
    conf = float(det[4:].max())
    cls = int(det[4:].argmax())
    if conf &gt; 0.5:
        cx,cy,bw,bh = det[:4]
        x1=int((cx-bw/2)*img.shape[1]/640); y1=int((cy-bh/2)*img.shape[0]/640)
        x2=int((cx+bw/2)*img.shape[1]/640); y2=int((cy+bh/2)*img.shape[0]/640)
        cv2.rectangle(img,(x1,y1),(x2,y2),(0,255,0),2)
        cv2.putText(img,f'cls:{cls} {conf:.2f}',(x1,y1-5),
            cv2.FONT_HERSHEY_SIMPLEX,0.6,(0,255,0),2)
        print(f'cls={cls} conf={conf:.2f} box=[{x1},{y1},{x2},{y2}]')
        count += 1

cv2.imwrite('/ros2_ws/result.jpg', img)
print(f'Total: {count} detections. Saved to workspace/result.jpg')
EOF</code></pre>
